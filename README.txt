Lucas Mateo Aguilar, portfolio site (from Mockup 22)

Open index.html in any browser. No build step and nothing to install.

PHOTOS TO ADD
Four of your photos live only on the design canvas, so they are not in this folder yet.
Save them into the images folder with these exact names:

  images/mateo.jpg            your photo for the "Hi, I'm Mateo." block
  images/dog.webp             the dog in the harness (AutoDog tile)
  images/jeans-sketch.jpg     the jeans photo (Sketch image inside the Upcycled Jeans book)
  images/finline-stools.webp  the Finline Stools photo

Already included: images/malawi-poster.jpg and images/code-graph.jpg.
Until a photo is added, its spot shows the colored placeholder.
A different file type works too (for example dog.jpg); just change the file name in index.html.

EDITING
All project text, colors and images are in the PROJECTS list near the bottom of index.html.
The tile sizes and their order are in LAYOUT, right below it.
To add photos inside a project's book, add bookImages, for example:
  bookImages: { 0: 'images/autodog-hero.jpg', 2: 'images/autodog-prototype.jpg' }
Slots: 0 Hero shot, 1 Sketch, 2 Prototype, 3 Detail, 4 Testing, 5 In use, 6 Final.
